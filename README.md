# Entorno Virtual Interactivo - Castillo de Niebla (Valdivia)

Proyecto de Realidad Virtual desarrollado en Unity para visores Meta Quest (standalone), enfocado en la puesta en valor y exploración interactiva del patrimonio histórico de Valdivia.

## Estructura del Repositorio
* `01_Modelos_3D/`: Archivos nativos de Blender (`.blend`) y modelos optimizados exportados (`.fbx`) del cañón, sable y capilla.
* `02_Texturas/`: Mapas de texturas, materiales PBR e imágenes de referencia.
* `03_Audio/`: Efectos de sonido ambientales y de interacción (`.wav`).

## Elementos Interactivos en RV
1. **Sable histórico:** Objeto manipulable mediante agarre directo con controladores VR.
2. **Cañón de defensa:** Elemento interactivo con retroalimentación sonora y física.
3. **Munición / Balas:** Objetos físicos manipulables dentro de la escena.
